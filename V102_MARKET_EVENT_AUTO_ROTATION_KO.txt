DalTownMap V102 - 마켓·행사 최신 자동 표시 + 관리자 고정

적용 내용
1. 마켓 정보와 행사 안내는 각 카테고리의 최신 후보 1건을 메인에 자동 표시합니다.
2. 관리자는 특정 후보의 '메인 고정' 버튼을 눌러 자동 교체를 멈출 수 있습니다.
3. 같은 카테고리에서 다른 후보를 고정하면 기존 고정은 자동 해제됩니다.
4. '고정 해제'를 누르면 다시 최신 후보 자동 표시로 돌아갑니다.
5. 날씨·교통은 기존처럼 자동 표시합니다.
6. 광고·업소는 기존처럼 관리자 지정 방식으로 유지합니다.

배포
- ZIP 전체를 Netlify에 배포합니다.
- 자동 메인 피드를 완전히 반영하려면 supabase/functions/newsroom/index.ts를 newsroom Edge Function으로 재배포합니다.
- Edge Function 재배포 전에도 Netlify 보조 피드와 관리자 화면에서는 최신 마켓·행사 자동 선택이 동작합니다.
