DalTownMap V89 - 달타운 알림 자동 브리핑

추가된 기능
1. 매일 달라스 라이프 자동 기사 1건이 게시되면 같은 작업에서 한 줄 브리핑도 생성합니다.
2. 브리핑은 newsroom_settings.home_config.daily_briefing에 저장됩니다.
3. 메인의 '달타운 알림' 우선순위는 다음과 같습니다.
   게시판 공지 → 관리자 직접 입력 → 오늘의 브리핑 → 업소 조건 → 숨김
4. 브리핑을 누르면 그날 자동 생성된 달라스 라이프 기사로 이동합니다.
5. date_key가 오늘 날짜인 브리핑만 표시하므로 오래된 문구가 다음 날 남지 않습니다.

적용
- supabase/functions/newsroom/index.ts 를 newsroom Edge Function으로 재배포
- 전체 사이트를 Netlify에 재배포
- 기존 V88 Cron SQL을 이미 실행했다면 Cron을 다시 만들 필요는 없습니다.
- 아직 실행하지 않았다면 supabase/newsroom-v61-daily-dallas-life-cron.sql의 SERVICE_ROLE_KEY를 교체한 뒤 SQL Editor에서 실행하세요.

주의
- 자동 기사 게시가 성공해야 브리핑이 생성됩니다.
- 당일 기사가 이미 있어서 게시를 건너뛴 경우 기존 당일 브리핑은 그대로 유지됩니다.
