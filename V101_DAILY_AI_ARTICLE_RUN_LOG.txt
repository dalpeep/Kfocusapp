DalTownMap V101 · AI 기사 자동 실행 기록 보완

적용 내용
1. 매일 최종 게시 작업이 실행될 때 newsroom_runs에 daily_publish 기록을 시작합니다.
2. 기사 게시 시: '기사 1건 게시 · 제목 · post_id' 메모를 남깁니다.
3. 후보가 없을 때: 성공 실행으로 처리하고 '게시하지 않음 · 사유' 메모를 남깁니다.
4. 오류 시: 실패 단계와 오류 내용을 남깁니다.
5. 관리자 AI 운영센터에 '오늘의 AI 기사 자동 게시' 상태 상자를 추가했습니다.
6. 실제 자동 게시된 기사는 newsroom_publications에도 날짜별로 기록합니다.

중요: Netlify ZIP 배포만으로 Edge Function은 바뀌지 않습니다.
- Netlify: 이 ZIP 전체 배포
- Supabase SQL Editor: supabase/newsroom-v63-daily-publish-log.sql 1회 실행
- Supabase Edge Functions: supabase/functions/newsroom/index.ts를 newsroom 함수로 재배포

배포 후 다음 실행부터 관리자 화면에 다음 중 하나가 표시됩니다.
- 기사 1건 게시
- 실행 완료 · 게시하지 않음 (사유 표시)
- 실행 실패 (오류 표시)
