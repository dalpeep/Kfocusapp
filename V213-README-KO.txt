DalTownMap V213 - 관리자 그룹 버튼 직접 제어

핵심 변경
1. 추천/신규/인기 자동 보충을 완전히 제거했습니다.
2. 관리자에서 추천을 누른 업체만 추천 목록에 표시됩니다.
3. 신규를 누른 업체만 신규 목록에 표시됩니다.
4. 인기를 누른 업체만 인기 목록에 표시됩니다.
5. 해제를 누르면 is_featured/is_new/is_popular 세 값이 모두 false로 저장되어
   즉시 해당 메인 목록에서 빠집니다.
6. 그룹이 6개 미만이면 임의 업체로 채우지 않고 실제 지정된 수만 표시합니다.
7. 전체 업소 화면은 기존처럼 모든 등록 업소를 유지합니다.

이 변경으로 관리자 버튼 = 관리자 현황 = AI 운영센터 목록 = 실제 메인 업소 탭이
동일한 저장값을 기준으로 움직입니다.
