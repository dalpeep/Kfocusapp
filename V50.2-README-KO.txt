Kfocusapp V50.2 - 메인 날씨·교통 카드 개선

반영 내용
1. 메인에 날씨와 교통 전용 모바일 카드 추가
2. 시각(예: 8:15 PM)은 표시하지 않고 상대 시간만 표시
   - 방금 업데이트 / N분 전 업데이트 / N시간 전 업데이트
   - 24시간 이상 오래된 경우 '업데이트가 지연되고 있습니다'
3. 상대 시간은 사용자가 화면을 연 시간이 아니라 서버 데이터의 updated_at 기준
4. 날씨·교통 카드 우측 상단에 새로고침 버튼 추가
5. 앱이 열려 있는 동안 5분마다 서버의 최신 홈 피드를 자동 재조회
6. Edge Function home_feed 응답에 updated_at 포함

중요
- 새로고침 버튼은 서버에 이미 수집·저장된 최신 데이터를 다시 읽습니다.
- 실제 원천 날씨·교통 정보 생성 주기는 Supabase의 newsroom auto_run 예약 주기에 따릅니다.
- 프론트엔드와 Supabase Edge Function을 모두 배포해야 updated_at 기준이 완전히 적용됩니다.
