DalTownMap V76 - 실제 서버 동기화 수정

원인:
- 이전 버전은 Supabase Edge Function의 새 home_settings 동작이 배포되어 있다는 전제였습니다.
- Netlify만 재배포한 경우 관리자 설정은 저장되어도 모바일 메인이 같은 설정을 읽지 못할 수 있었습니다.

수정:
1. Netlify Function runtime-settings.js 추가
2. 관리자 이벤트 루틴 저장/조회가 이 공통 엔드포인트를 사용
3. 모바일 메인도 같은 엔드포인트에서 설정 조회
4. 달타운 알림은 공지 게시글 우선, 공지가 없으면 직접 입력 문구 표시
5. 추천/알림/커뮤니티 설정이 동일한 서버 값을 사용

배포 후 관리자에서 이벤트 루틴을 한 번 저장하고 모바일 페이지를 다시 여세요.
