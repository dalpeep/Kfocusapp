DalTownMap V60

변경 사항
1. AI 달라스 라이프 기사 마지막에 "생활 한 줄:" 실용 문구를 자동 추가합니다.
2. 사용자 기사 본문에서는 출처·원문·URL 푸터를 제거합니다. 출처 정보는 newsroom_items에 내부 보관합니다.
3. 사용자 앱은 커뮤니티 탭 재진입, 앱 포커스 복귀, 화면 재활성화 시 게시글을 자동 갱신합니다.
4. 앱을 계속 열어둔 경우 5분마다 조용히 게시글을 다시 확인합니다.
5. 실제 기사 생성 주제는 생활·교육·의료·교통·세금·재정·부동산으로 유지합니다.

배포
- 전체 프로젝트를 Netlify에 배포합니다.
- supabase/functions/newsroom/index.ts를 newsroom Edge Function으로 다시 배포합니다.
- 앱 코드 캐시 갱신을 위해 첫 1회 새로고침이 필요할 수 있습니다. 이후 DB 게시글은 자동 갱신됩니다.
