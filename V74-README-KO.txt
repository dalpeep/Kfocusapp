DalTownMap V74 업그레이드

1. Supabase SQL Editor에서 다음 파일을 실행합니다.
   supabase/v74-board-alert-notice.sql

2. 프로젝트 전체를 배포합니다.

3. 관리자 > 게시판·가이드 관리
   - 달타운 공지 체크
   - 공지 순서 입력
   - 저장

4. 관리자 > 이벤트 루틴
   - 달타운 추천: 추천/신규/인기/쿠폰/배너/주소 기반/관리자 지정/랜덤 업체
   - 주소 기반 업체 선택 시 영문 주소 검색어를 한 줄씩 입력
   - 달타운 알림: 게시판 공지 전용

5. 이벤트 루틴을 한 번 다시 저장한 뒤 메인 화면을 새로고침합니다.

구조
- 달타운 추천: 업소 데이터만 사용
- 달타운 알림: is_alert_notice=true 게시글만 사용
- 커뮤니티: 기존 고정글 및 최신글 슬라이더 유지
