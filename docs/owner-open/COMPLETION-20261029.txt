사용 완료 버튼 중복 클릭 차단. 쿠폰 코드/이메일을 비인증 발급 접수 응답으로 반환하지 않음.
알림 상태: mock 경로 및 주입형 발송/재시도 도우미 검증 READY. 실제 provider와 무인 주기 worker의 운영 연결은 INCOMPLETE/비활성. 실제 수신 PASS로 보고하지 않음.

2. 업종별 한영 소개 — 사용자 추가 지시 반영
기존 승인 원본이 없음을 확인하여 12개 그룹·48개 한국어/영어 문구를 새로 작성.
일반, 식당, 카페·베이커리, 미용·뷰티, 쇼핑·생활용품, 자동차, 주거·수리·청소, 교육·학원, 운동·취미, 반려동물, 전문·상담, 여행·숙박.
원본: supabase/owner-open/data/description-catalog.json (version 1).
문구는 면허·효과·가격·직원 자격 등을 임의로 보장하지 않는 안내형 문장.
UI: 현재 업종 + 일반 문구에서 한국어/English 선택. 미분류 업종은 일반 문구 제공. Free 자유 입력/소개 이미지 업로드 불가, Paid 자유 소개/이미지 정책 유지.
신규 등록의 업종 입력 단계에 선택 항목 연결. 신청에는 문구 ID와 당시 텍스트 보존. 관리자 승인 시 새로 생성된 업소에만 적용.
기존 소개는 선택지에서 그대로 유지 가능하며 일괄 수정하지 않음. 같은 승인키 재실행 시 이후 업주가 바꾼 소개를 덮어쓰지 않음.
기존 업소 변경은 현재 소개 그대로 유지하거나 해당 업종의 활성 문구만 허용. 다른 업종·임의 문장은 서버/DB에서 거부.
카탈로그 그룹/언어/활성/순서 필드를 분리하여 추후 관리자 기능 확장 가능. 현재 별도 관리자 편집 UI는 추가하지 않음.
12번 seed는 기존 ID를 덮어쓰지 않음. 향후 기존 문구 수정·비활성화는 별도 검토 Migration으로 처리하며 기존 업소 내용은 자동 변경하지 않음.
