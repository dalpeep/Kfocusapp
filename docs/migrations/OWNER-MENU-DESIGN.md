# 업주 메뉴 관리

운영 카탈로그의 public 스키마에서 메뉴 전용 테이블이나 businesses의 메뉴 전용 컬럼을 찾지 못했다. 할인 항목인 business_special_items는 기간·요일이 있는 스페셜에 연결되므로 상시 메뉴의 저장소로 사용하지 않는다.

신규 business_menu_items는 업소 UUID, 항목 UUID, 한글·영문 메뉴명, 설명, USD 센트 단위 가격, 이미지 참조, 표시 순서, 공개 상태, 수정 시각을 저장한다. 업소 외래키는 ON DELETE RESTRICT를 사용한다. 종료 또는 메뉴 제거는 비공개 처리로 구현해 기존 기록과 Storage 원본을 보존한다.

공개 조회는 표시 가능한 업소의 공개 항목으로 제한한다. 등록·편집·숨김·정렬 RPC는 service_role로만 실행하며 기존 파일럿과 승인된 업소 연결을 검증한다. 이미지 업로드는 owner-phase2 업소별 경로를 재사용한다. 정렬은 같은 업소의 항목만 한 트랜잭션에서 갱신한다.

격리 검증 대상은 익명·일반 사용자 직접 쓰기, 업주 간 교차 접근, 공개 범위, 중복 요청, 정렬 충돌, 가격과 이미지 검증이다. 운영 적용 전에 검증된 롤백은 RPC 실행을 먼저 차단하고 데이터를 보존하는 방향으로 준비한다.
