# 유료 프로모션 운영 기준

관리자 쿠폰 화면의 이메일 응모·추첨 방식은 현재 메인·지도 프로모션의 데이터 출처다. 광고 업소, 이미지, 광고 시작·종료, 순서, 활성 상태는 기존 필드를 사용한다. 추천·메인 슬라이드 표시는 별도 노출 옵션이다.

유료 프로모션 등록·수정·종료는 super_admin만 가능하다. 종료 시 비활성화해 응모·발급·사용 기록을 보존한다. 기존 쿠폰과 프로모션 간 유형 전환은 차단한다. 업주센터의 콘텐츠 관리 범위는 승인된 업소의 사진·쿠폰·할인·이벤트 및 향후 메뉴다. 온라인 결제와 자동 청구는 범위에서 제외한다.
