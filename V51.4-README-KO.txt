Kfocusapp V51.4

핵심 변경
1. AI 수집 원문은 자료 출처일 뿐이며 게시 기사에 원본 링크를 자동으로 넣지 않습니다.
2. 관리자 옵션을 “게시판 기사로 발행”과 “오늘의 달타운 메인 노출”로 분리했습니다.
3. 업소 홍보용 콘텐츠는 기사 발행 없이 메인에만 노출하고 선택한 업소 상세로 연결할 수 있습니다.
4. 기사 발행을 선택한 경우에만 게시 위치를 선택합니다.
5. 외부 링크는 기본 비활성화이며 관리자가 직접 입력한 경우에만 게시물에 표시됩니다.
6. 메인 자동 항목은 날씨와 교통만 유지합니다. 쇼핑·행사·업소·교육·부동산·금융 등은 관리자가 메인 노출을 지정한 경우에만 표시됩니다.
7. 수동 업소 검색 상태와 선택을 유지하도록 수정했습니다.
