V53.2 실제 로드 파일 동기화 수정

핵심 원인:
- 관리자 페이지는 /admin/assets/admin.js를 불러오는데, 이전 패치가 루트 /admin.js에만 적용되어 실제 화면에는 반영되지 않았습니다.

수정:
1. /admin/assets/admin.js에도 null 안전 처리와 메인 현황판 코드를 동일하게 반영
2. 삭제된 가이드/행사 박스가 없어도 게시 저장이 중단되지 않음
3. 선택적 newsroom_runs 테이블을 일반 로딩 중 조회하지 않아 404가 저장 흐름을 방해하지 않음
4. 관리자 JS 캐시 버전을 53.2로 변경

배포:
- ZIP 전체를 Netlify에 배포
- 이번 수정은 프론트엔드 실제 로드 파일 수정이 핵심이므로 Supabase Edge Function 재배포는 필수 아님
- 배포 후 Ctrl+Shift+R
