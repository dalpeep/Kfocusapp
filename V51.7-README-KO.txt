DalTownMap V51.7

변경 사항
1. 기사 게시 위치를 달라스 라이프 / 달라스 가이드 두 가지로 단순화했습니다.
2. 기존 가이드 선택 및 업데이트 세부 창을 제거했습니다.
3. 메인 표시 구성 안내를 추가했습니다.
   - 날씨: 자동
   - 교통: 자동
   - 마켓 정보: 관리자 지정
   - 행사 안내: 관리자 지정
   - 광고·업소: 관리자 지정
4. 관리자 지정 메인 카드가 Edge Function 배포 상태와 무관하게 Netlify Function을 통해 공개 피드에 반영되도록 보완했습니다.

배포
- ZIP 전체를 Netlify에 배포하세요.
- Netlify 환경변수 SUPABASE_URL 및 SUPABASE_SERVICE_ROLE_KEY가 필요합니다. 기존 뉴스룸 기능을 사용 중이면 대개 이미 설정되어 있습니다.
