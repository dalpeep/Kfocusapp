DalTownMap Newsroom V48.8

핵심 동작
1. 관리자가 지정한 기사가 한 건이라도 있으면 해당 기사만 메인에 표시됩니다.
2. 관리자 지정 기사들은 같은 카테고리여도 각각 별도 슬라이드로 표시됩니다.
3. 관리자 지정 자체가 공개 승인입니다. 메인 링크는 선택 사항입니다.
4. 관리자가 지정한 기사가 없으면 AI가 자동으로 기사를 선별해 링크 없이 표시합니다.
5. 자동 공개 기사에는 원문 링크나 카테고리 공통 링크를 자동 연결하지 않습니다.
6. 관리자가 기사별 '메인 링크 설정'을 한 경우에만 해당 링크가 활성화됩니다.
7. 매일 오전 6시 auto_run 시작 시 전날 관리자 지정과 기사별 메인 링크를 모두 초기화합니다.
8. 초기화 후 예정 기사 우선 수집과 AI 자동 선별이 다시 시작됩니다.

적용
- Supabase Edge Functions > newsroom > Edit Code에서
  supabase/functions/newsroom/index.ts 전체를 교체 후 Deploy
- 프로젝트 전체를 Netlify에 배포
- 정상 Edge Function 버전: 48.8.0
