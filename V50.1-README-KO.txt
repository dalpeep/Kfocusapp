DalTownMap V50.1 — 오늘의 달라스 + 현재 위치 유지

지도 수정
- 현재 위치 좌표를 지도 중심 좌표와 분리해 보관합니다.
- 업소 클릭, 지도 이동, 확대/축소, 필터 변경 후에도 현재 위치 마커를 유지합니다.
- "현재 위치 표시 중" 말풍선을 마커 위에 계속 표시합니다.
- watchPosition으로 사용자의 위치가 바뀌면 마커와 말풍선을 갱신합니다.
- 달라스 클라이언트는 달라스 업소만 표시하며 타 지역 전환 기능은 추가하지 않았습니다.

날씨·교통 갱신 권장값
- 날씨: 10~15분 간격
- 교통: 5~10분 간격
- 앱을 다시 열거나 홈으로 돌아올 때 즉시 최신 저장값 재조회

주의
- 실시간 갱신은 외부 데이터 제공 주기와 Supabase 예약 실행 주기에 따라 달라집니다.
- 초 단위 실시간이 아니라 '준실시간' 방식이 현실적입니다.
- 웹사이트 전체와 Supabase newsroom Edge Function을 함께 배포해야 V50 메인과 수집 기능이 모두 적용됩니다.
