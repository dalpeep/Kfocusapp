DalTownMap V49.2 뉴스룸 통합 관리

변경 사항
- 중복되던 '오늘 수집된 기사' 요약 목록과 '전체 목록'을 하나로 통합했습니다.
- 통합 목록에서 기사 선택, 검토, 관리자 지정/해제, 내부 연결, 보관, 삭제를 처리합니다.
- 전체 선택/선택 해제 기능을 유지했습니다.
- 선택 기사 일괄 관리자 지정/해제 기능을 유지했습니다.
- 선택 기사 일괄 보관/보관 해제 기능을 추가했습니다.
- 선택 기사 일괄 삭제 기능을 추가했습니다.
- 현재 표시 목록 전체 삭제 기능을 추가했습니다.
- 전체 삭제는 실수 방지를 위해 확인창과 기사 수 재입력을 요구합니다.
- 검색 또는 필터가 적용된 상태에서는 현재 표시된 기사만 전체 삭제됩니다.

- admin/assets/admin.js JavaScript 구문 검사 완료
- ZIP 무결성 검사 완료
