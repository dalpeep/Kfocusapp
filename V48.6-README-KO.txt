DalTownMap Newsroom V48.6

메인 공개 규칙
1. 관리자 지정 기사가 하나라도 있으면 자동/예정/카테고리 기사를 섞지 않습니다.
2. 관리자 지정 기사 중 '메인 링크 설정'까지 완료된 기사만 실제 메인에 공개됩니다.
3. 관리자 지정은 했지만 링크가 없는 기사는 검토 중으로 남으며 메인에 노출되지 않습니다.
4. 관리자 지정 기사가 전혀 없을 때만 예정 기사 -> 선택 카테고리 -> AI 자동 대체가 작동합니다.
