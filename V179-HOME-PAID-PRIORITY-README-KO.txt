V179 홈 업소 6개 / 유료 우선 / 무료 자동 보충

1. 추천·신규·인기 각 탭은 홈에서 최대 6개 노출합니다.
2. 노출 우선순위:
   - 유료 광고 + 로테이션 OFF: 고정 우선
   - 유료 광고 + 로테이션 ON: 날짜/가중치 기반 자동 로테이션
   - 유료 광고가 6개 미만: 일반 업소가 빈 자리를 자동 보충
3. 무료 자동 보충은 해당 그룹에 편성된 일반 업소를 우선 사용하고, 그래도 부족하면 전체 활성 업소에서 채웁니다.
4. 신규 무료 보충은 최근 등록 순을 우선합니다.
5. 관리자 광고센터 > 로테이션 미리보기에서 '유료 고정 / 유료 자동 로테이션 / 무료 자동 보충' 상태를 확인할 수 있습니다.
6. 유료 광고가 6개 이상이면 무료 업소는 홈 해당 탭에서 자동으로 빠집니다.
